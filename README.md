# Government Approved Computer Institute — React 19 + Vite

## Setup & Run Locally

1. Extract this ZIP file and open the folder in your terminal.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open the local URL shown in your terminal (usually `http://localhost:5173`).

## Customization
- Replace placeholders like `[YOUR SCHOOL NAME LTD]`, `[YOUR RC NUMBER]`, `[+234 000 000 0000]`, and `[info@yourdomain.com]` inside `src/App.jsx`.
- Add your images and `.mp4` video paths inside `public/` and reference them in `src/App.jsx`.
